# Лабораторная работа 1. Исследование типов данных

Лабораторная работа по курсу «Программирование на C++». Посвящена исследованию целых и вещественных типов данных, а также сравнению производительности битовых и арифметических операций.

## Структура работы

Работа оформлена как единый CMake-проект. Каждое задание — в отдельной папке:

```
lab_datatypes/
├── CMakeLists.txt
├── 01_task/      ← Задание 1. Битовые операции
├── 02_task/      ← Задание 2. Переполнение целых
├── 03_task/      ← Задание 3. Вещественные числа (IEEE 754)
├── 04_task/      ← Задание 4. Битовые vs арифметические операции
└── 05_task/      ← Задание 5. Влияние типа данных на скорость
```

В каждой папке `NN_task/`:
- `main.cpp` — самодостаточная программа (без глобальных переменных),
- `CMakeLists.txt` — сборка отдельного исполняемого файла `taskNN`,
- `README.md` — ответы на вопросы и выводы по заданию.

## Содержание заданий

### Задание 1. Представление целых чисел. Битовые операции
- Вывод 32-битного представления числа `+42`.
- Битовые операции `&`, `|`, `^`, `~`, `<<`, `>>` для `a = 42`, `b = −17`.
- Разбор дополнительного кода, `−1` в прямом/обратном/дополнительном коде.
- Объяснение поведения сдвига вправо для знаковых и беззнаковых.

### Задание 2. Переполнение целочисленных типов
- Демонстрация `UINT32_MAX + 2` и `INT32_MAX + 2`.
- Разбор битового представления результата.
- Почему беззнаковое переполнение безопасно, а знаковое — UB.

### Задание 3. Особенности вещественных чисел
- Представление `10.25` и `7.1` во `float` по IEEE 754 (с вычислениями).
- Сумма `10.25 + 7.1` и объяснение расхождения с точным `17.35`.
- Нарушение ассоциативности сложения.
- Проблема строгого сравнения `==` для вещественных чисел.

### Задание 4. Битовые vs арифметические операции
- Замеры времени для пар `(x/2, x>>1)`, `(x*2, x<<1)`, `(x%2, x&1)`.
- N = 10⁸ итераций, `volatile`, `int32_t` и `uint32_t`.
- Анализ: в каких случаях битовая операция быстрее и почему.

### Задание 5. Влияние типа данных на скорость вычислений
- Замеры времени сложения `x += 1` для 8 типов: `char`, `short`, `int`, `unsigned char`, `unsigned short`, `unsigned int`, `float`, `double`.
- Две версии: с `volatile` и без, профиль Release.
- Анализ: влияние `volatile`, размера типа, знаковости, FPU.

## Требования

- CMake ≥ 3.10
- Компилятор C++ с поддержкой **C++23** (GCC 13+, Clang 16+)

## Сборка

Из корня лабы:

```bash
cmake -S . -B cmake-build-release -DCMAKE_BUILD_TYPE=Release
cmake --build cmake-build-release
```

Будут собраны 5 исполняемых файлов: `task01`, `task02`, `task03`, `task04`, `task05`.

## Запуск отдельного задания

```bash
cmake --build cmake-build-release --target taskNN
./cmake-build-release/NN_task/taskNN
```

Например:

```bash
cmake --build cmake-build-release --target task04
./cmake-build-release/04_task/task04
```

## Запуск в CLion

1. Открыть корневую папку `lab_datatypes` как проект.
2. В списке конфигураций выбрать нужную цель (`task01` … `task05`).
3. Нажать **Run** (▶).

## Примечания

- Использование **глобальных переменных запрещено** — все данные передаются через параметры и возвращаемые значения функций.
- Каждая папка `NN_task` **самодостаточна**: запуск одного задания не зависит от других.
- Папки сборки (`cmake-build-*`) в репозиторий не попадают (см. `.gitignore` в корне репозитория).
