# Задание 2. const с указателями и ссылками

## 1. Чем отличается `const int* p` от `int* const p`?

| Запись         | Что const     | Можно менять `*p` | Можно менять `p` |
|----------------|---------------|-------------------|------------------|
| `const int* p` | данные        | нет               | да               |
| `int* const p` | сам указатель | да                |              нет |

- `const int*` — «указатель на константу»: значение по адресу менять нельзя, переприсвоить указатель можно.
- `int* const` — «константный указатель»: адрес фиксирован, значение менять можно.

Примеры:
```cpp
int a = 1, b = 2;
const int* p1 = &a;  // *p1 = 5 — нельзя; p1 = &b — можно
int* const p2 = &a;  // *p2 = 5 — можно; p2 = &b — нельзя
