# Лабораторная работа №2. Динамические массивы, указатели и функции

## Цель работы

Закрепить практические навыки работы с динамической памятью, указателями,
ссылками и функциями в C++.

## Задачи

1. Изучить различия между передачей параметров в функцию **по значению**,
   **по указателю** и **по ссылке**.
2. Освоить применение модификатора `const` с указателями и ссылками
   для защиты данных.
3. Исследовать представление статических и динамических массивов в памяти,
   понять принципы адресной арифметики.
4. Научиться корректно работать с динамически выделяемой памятью:
   создавать массивы, передавать их в функции, изменять и освобождать.
5. Попрактиковаться в организации модульного проекта с использованием
   системы сборки CMake.

## Краткое содержание заданий

| № | Задание | Ключевые понятия |
|---|---|---|
| 1 | Три версии `modify` | передача по значению, указателю, ссылке |
| 2 | `const int*`, `int* const`, `const int&` | защита данных, различие «указатель на константу» и «константный указатель» |
| 3 | Статический и динамический массивы | `sizeof`, адресная арифметика, время жизни |
| 4 | Передача динамического массива в функцию | `int*&`, копия указателя, `reallocate` |
| 5* | Зубчатая матрица `int**` | `new int*[rows]`, `delete[]`, `resizeMatrix` |

## Сборка

```bash
mkdir build && cd build
cmake ..
cmake --build .
```

Исполняемые файлы появятся в `build/`:
`01_task`, `02_task`, `task03`, `04_task`, `05_task`.

### Отладка утечек памяти

Задание 5 собирается с AddressSanitizer:

```cmake
target_compile_options(05_task PRIVATE -fsanitize=address -g)
target_link_options(05_task PRIVATE -fsanitize=address)
```

При наличии утечек, `double free` или использования после `delete[]`
ASan выведет подробный отчёт.

## Требования

- C++23 (`set(CMAKE_CXX_STANDARD 23)`)
- CMake ≥ 3.10
- Никаких глобальных переменных — все данные передаются через параметры.
- Код разделён на `.h` / `.cpp`, в заголовках используется `#pragma once`.
- В каждом `README.md` задания — ответы на контрольные вопросы.
