# Задание 1. Передача параметров в функцию

## Описание

Реализованы три версии функции `modify`, демонстрирующие различия между
передачей параметров **по значению**, **по указателю** и **по ссылке**.

## Файлы

- `modifiers.h` — объявления функций
- `modifiers.cpp` — реализации функций
- `main.cpp` — демонстрация работы

## Функции

| Функция | Способ передачи |
|---|---|
| `modifyByValue(int x)` | по значению |
| `modifyByPointer(int* x)` | по указателю |
| `modifyByReference(int& x)` | по ссылке |

## Ответы на вопросы

### 1. Почему при передаче по значению исходные переменные не меняются?

При передаче по значению в функцию попадает **копия** аргумента.
Все изменения внутри функции применяются к этой копии, которая живёт
в отдельной области памяти (в стеке функции). После выхода из функции
копия уничтожается, а оригинальная переменная в вызывающем коде
остаётся нетронутой.

### 2. В чём разница между указателем и ссылкой при передаче?

| Свойство | Указатель | Ссылка |
|---|---|---|
| Может быть `nullptr` | да | нет |
| Можно переприсвоить | да | нет |
| Требует разыменования | да (`*p`) | нет |
| Синтаксис в теле функции | как с указателем | как с обычной переменной |
| Хранит адрес | явно | неявно |

Указатель — это самостоятельная переменная, хранящая адрес.
Ссылка — это псевдоним уже существующего объекта.

### 3. Когда безопаснее использовать ссылку, а когда — указатель?

- **Ссылка** — когда объект гарантированно существует и не может
  отсутствовать. Код получается чище и безопаснее: нельзя случайно
  разыменовать `nullptr` или забыть про `*`.
- **Указатель** — когда параметр может быть «пустым» (`nullptr`),
  когда нужна адресная арифметика или работа с динамическими
  массивами.

### 4. Какой способ предпочтительнее для передачи больших объектов, если они не должны меняться?

`const T&` — **константная ссылка**.

Причины:
- объект не копируется (нет накладных расходов на копирование);
- компилятор запрещает изменять объект внутри функции;
- интерфейс функции сразу сообщает читателю: «этот параметр только для чтения».

### 5. Происходит ли при передаче копирование? Что именно копируется?

| Способ передачи | Что копируется | Влияет ли на оригинал |
|---|---|---|
| по значению | копия всего объекта | нет |
| по указателю | копия указателя (адреса) | да, через `*p` |
| по ссылке | ничего не копируется | да, напрямую |

- **По значению** — копируется весь объект целиком. Изменения не видны снаружи.
- **По указателю** — копируется только указатель (8 байт на 64-битной системе).
  Сам объект один, поэтому через `*p` можно его изменить.
- **По ссылке** — не копируется ничего. Функция работает с оригиналом
  через неявный указатель, но синтаксически — как с обычной переменной.
