## Задание 3. Особенности вещественных чисел

`float`/`double` реализуются по IEEE 754 и обладают рядом особенностей: операции неточны и не всегда подчиняются привычным математическим свойствам.

**Схема решения:**

   - (в) Запустить код и показать `10.25 + 7.1` с `setprecision(12)`. Объяснить результат.

3. **Сравнение на равенство.** Объяснить, почему `a == b` для вещественных небезопасно и к чему может привести.

## Справка: измерение времени через `<chrono>`

Схема замера:

1. Замерить время `start` до операции.
2. Выполнить операцию (в цикле с большим N).
3. Замерить время `end` после.
4. `duration = end − start`.

```cpp
#include <iostream>
#include <chrono>

int main() {
    const size_t N = 1000000;
    volatile int x = 42;

    auto start = std::chrono::high_resolution_clock::now();
    for (size_t i = 0; i < N; ++i) {
        x = 42;       // сброс значения
        x = x / 2;    // измеряемая операция
    }
    auto end = std::chrono::high_resolution_clock::now();

    auto duration = std::chrono::duration<double, std::micro>(end - start);
    std::cout << "Время: " << duration.count() / N << " мкс\n";
    return 0;
}
```

**Важно:**

- Использовать `volatile`, чтобы компилятор не выбросил переменную при оптимизациях.
- Оборачивать операцию в цикл с **большим N** (≈ 10⁸), иначе операция может занять менее наносекунды.
- Сравнивать производительность в **одинаковых условиях** (машина не должна быть нагружена).

## Задание 4. Битовые vs арифметические операции

Измерить время выполнения пар операций в цикле **N = 10⁸** итераций (использовать `volatile`):

| Операция | Арифметический аналог | Битовый аналог |
|---|---|---|
| Деление на 2 | `x / 2` | `x >> 1` |
| Умножение на 2 | `x * 2` | `x << 1` |
| Проверка чётности | `x % 2 == 0` | `(x & 1) == 0` |

**Схема решения:**

- Использовать `uint32_t` и `int32_t` (подключить `<cstdint>`). Сравнить оба.
- Для каждой операции — отдельный замер.
- Обязательно `volatile` — и для результата, и для делимого.
- **Восстанавливать значение** переменной внутри цикла, иначе быстро получится 0.

Вывести таблицу в консоль:

```

int32_t   Деление на 2      ...               ...
int32_t   Умножение на 2    ...               ...
int32_t   Чётность          ...               ...
uint32_t  Деление на 2      ...               ...
uint32_t  Умножение на 2    ...               ...
uint32_t  Чётность          ...               ...
```

**Вопрос (README):** медленнее или быстрее битовая операция арифметической? В каких случаях да, в каких нет? Почему?
