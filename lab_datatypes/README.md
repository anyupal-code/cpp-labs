# Лабораторная работа №1. Исследование разных типов данных

## Цель работы

Исследовать особенности целых и вещественных чисел, а также
производительность различных операций и типов данных.

## Задачи

- Изучить особенности работы с целыми и вещественными типами данных,
  представление чисел в памяти по стандарту IEEE 754.
- Исследовать время выполнения базовых арифметических и битовых операций
  для различных целочисленных типов.
- Изучить влияние типа данных на скорость выполнения операций.
- Попрактиковаться с подключением библиотек (в т.ч. `<chrono>`).
- Попрактиковаться в организации модульного проекта на CMake.

## Структура проекта


## Что нужно сделать

### Задание 1. Представление целых чисел. Битовые операции
- Вывести 32-битное представление числа `+42` (от старшего бита к младшему).
- Для `a = 42`, `b = −17` вывести результаты `&`, `|`, `^`, `~`, `<< 2`, `>> 2`.
- Ответить на вопросы в `01_task/README.md`: разбор каждой операции
  с битовым представлением, прямой/обратный/дополнительный код `−1`,
  устройство и смысл дополнительного кода, поведение сдвига вправо
  для отрицательных чисел.

### Задание 2. Переполнение целочисленных типов
- Для `uint32_t` выполнить `UINT32_MAX + 2`, показать результат в коде.
- Для `int32_t` выполнить `INT32_MAX + 2`, показать результат в коде.
- Ответить на вопросы в `02_task/README.md`: битовое представление
  результатов, почему беззнаковое переполнение безопасно,
  а знаковое — нет, что говорит стандарт C++.

### Задание 3. Особенности вещественных чисел
- Показать перевод `10.25` и `7.1` во `float` с вычислениями и
  представлением в памяти.
- Вывести сумму `10.25 + 7.1` с `setprecision(12)` и объяснить результат.
- Продемонстрировать нарушение ассоциативности: `(a + b) + c ≠ a + (b + c)`.
- Объяснить, почему строгое сравнение `a == b` для вещественных небезопасно.
- Ответить на вопросы в `03_task/README.md`.

### Задание 4. Битовые vs арифметические операции
- Замерить время пар операций для `uint32_t` и `int32_t`, N = 10⁸ итераций,
  с `volatile`:

  | Арифметика | Битовая |
    |---|---|
  | `x / 2` | `x >> 1` |
  | `x * 2` | `x << 1` |
  | `x % 2 == 0` | `(x & 1) == 0` |

- Вывести таблицу результатов в консоль.
- В `04_task/README.md` вставить таблицу и ответить: когда битовая
  операция быстрее арифметической, когда нет и почему.

### Задание 5*. Влияние типа данных на скорость вычислений
- Для типов `char`, `short`, `int`, `unsigned char`, `unsigned short`,
  `unsigned int`, `float`, `double` замерить время `N` сложений с `1`
  при N = 10⁸.
- Сделать две версии: **с** `volatile` и **без** `volatile`.
- Вывести две таблицы: тип, размер (`sizeof`), время.
- В `05_task/README.md` вставить таблицы и ответить: влияние `volatile`,
  размера типа, знаковости, поведение `float`/`double` по сравнению
  с целыми.

## Сборка

```bash
mkdir build && cd build
cmake ..
cmake --build .
```

Исполняемые файлы появятся в `build/`: `task01`, `task02`, `task03`, `task04`, `task05`.

## Требования

- C++23 (`set(CMAKE_CXX_STANDARD 23)`)
- CMake ≥ 3.10
- Никаких глобальных переменных — все данные передаются через параметры
  и возвращаемые значения функций.
- Каждый `main.cpp` самодостаточен — запуск задания не зависит от других папок.
- В каждом `README.md` задания — ответы на контрольные вопросы и выводы.
